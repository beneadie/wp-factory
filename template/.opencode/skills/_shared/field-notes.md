# Field Notes

Per-site lessons that should improve the next discovery pass. Keep entries
short. If a lesson generalises, promote it to `plugin-fingerprints.md`,
`risk-rubric.md`, or the relevant skill.

## Template

```markdown
## YYYY-MM-DD — short title

- Capability:
- Signal (route, field, header, script, page):
- What we tried:
- Result / status:
- Decision:
- Generalise? yes/no — where:
```

## Rules

- Record the evidence, not just the conclusion.
- Record rejected paths; they save the next agent from repeating them.
- No customer data, tokens, cookies, or secrets.
- If a route or plugin behaves differently from its documentation, say so.
